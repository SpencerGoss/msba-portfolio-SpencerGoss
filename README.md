# msba-portfolio-SpencerGoss
This is a portfolio of a case project that was completed in the MSBA program at the University of Louisville.
We were given a customer data set consisting of 5636 rows of which contains demographics and behavioral charataristics of the customers such as type of service.
We were asked to use this data to make a predictive model to identify churn risk as well as identify key factors that could be influencing this churn and thus give data driven recomendations

Key Results Found:
- Newest customers (those with 0-6 month tenure) coupled with month to month are at the most risk of churn comparatively
- Customer that reffer others are significantly at less risk of churning
- Customers can be segmented into three clusters and each at risk customer should be handled differently based on cluuster

How to Run Code:
1. Download retentiondata_case located in reposition
2. Open code labeled ChurnCaseFinalModels in Jupyter or any program that is able to run python (make shure retentiondata_case is uploaded to program)
3. Run Code (takes a while to run, would not recomend running on older tech)

Limitations About Findings
- Findings do not mean causation and are rather to gain insights on what could be the posible factors causing customers to churn
- Modeling can be improved with better processing power as my device cannot handle extensive modeling
